Before your interview

  1. Keep Safari open on your iPhone, place it sideways, and connect it to power.
  2. Choose PocketLens in Zoom, Teams, or Meet’s camera settings.
  3. Choose your headset or laptop microphone separately.
  4. Run a practice call in the app you’ll use. Keep the laptop camera available as a backup.

First time? Set up Safari access

Safari requires a trusted HTTPS connection before it can use your camera. Complete these steps once, then scan the pairing code above.

  1. Scan this setup code and download the local certificate profile.
  2. In Settings → General → VPN & Device Management, install PocketLens — local HTTPS.
  3. In Settings → General → About → Certificate Trust Settings, enable PocketLens Local CA.
  4. Scan the first QR code and tap Start camera.

Only install the profile served by your own laptop. The profile adds a certificate authority, not device management. Remove it when you stop using this app.

Connection help

If the iPhone cannot open the setup page, allow the receiver through Windows Firewall using Allow PocketLens Network.ps1 in the app folder. It allows the setup and video ports, plus WebRTC UDP, from your local subnet. Guest Wi-Fi may prevent devices from reaching each other.

Restart the meeting app if the camera is missing. Start this receiver before selecting the camera. On a managed work account, your organization may restrict virtual cameras.
